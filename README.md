# Bookstore Intelligence Mission

This project scrapes book data (title, price, rating, availability and product URL) from books.toscrape.com using Python.
It loops through all 50 catalogue pages, converts the word ratings to numbers 1-5, and saves 1,000 books to competitor_books.csv.
The notebook then answers the business questions and solves the £100 market-research challenge.
Tools used: requests, BeautifulSoup, pandas, NumPy and Matplotlib.
To run it, install these libraries and run the notebook Sohaib_23i5030_Assgn3.ipynb from top to bottom.# bookstore-scraper-
